===============
Site FAQs
===============

The Site FAQs are a collection of basic pages. 

As a general rule, Site FAQ pages are:

* Titled FAQ: [topic]
* Given a path alias of /site-faqs/[title]
* Use a media and text block to list the questions and answers
* Are linked to from the main site faq landing page
* Have two automatic blocks that:

  * Provide an "About ILAO" explainer message
  * Link to the other FAQ pages
  
Site FAQs are linked to from the footer.
